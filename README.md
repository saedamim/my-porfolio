## ✨ Features

- **Responsive Design:** Works across desktop, tablet, and mobile devices.
- **About Me:** Introduction, programming journey, and career interests.
- **Skills Section:** Showcases technical skills and development tools.
- **Education & Experience:** Highlights academic background and relevant experience.
- **Projects Showcase:** Displays projects with screenshots, descriptions, live demos, and dedicated details pages.
- **Resume Page:** View, print, or save the resume as a PDF.
- **Contact Section:** Provides email contact and a prefilled email form.
- **Social Links:** Quick access to GitHub and LinkedIn profiles.

## 💻 Getting Started

### Prerequisites

- Node.js 20.9 or newer
- npm

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/saedamim/my-portfolio.git
   ```

2. Navigate to the project directory:

   ```bash
   cd my-portfolio
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open [http://localhost:3000](http://localhost:3000) in your browser.

### Available Commands

```bash
npm run dev
npm run lint
npm run build
```
